# Every building

Every building, piece of furniture and plant this mod adds.

## Buildings and furniture

| | Name | Value | What it is |
|---|---|---|---|
|  | **Cobweb** |  | An ordinary-looking cobweb. Whoever walks through it, the spider who spun it knows. |
|  | **Kin web** |  | A tangle of web in a dark corner where an Ananasi's spider kin live. A female Ananasi needs one on the map to lay an egg sac. |
|  | **Paper box** |  | A folded paper box, Umekochi's Mouth, that holds four stacks in one cell. It unfolds after a day. |
|  | **Rat-hole** |  | A narrow hole into the Ratkin's tunnels. A Ratkin in war form or rat form goes down it and comes out at another rat-hole on the map, fast and out of sight. |
|  | **Sylie** |  | A great cobweb spun in a quiet corner, here and in the spirit world both: an Ananasi's lair. In its room the Ananasi regains Gnosis and can step sideways more easily. |
|  | **Web floor** |  | Sticky web spread over the ground. Anyone crossing it wades. |
|  | **Web wall** |  | A wall of spider silk nearly as strong as steel. Nobody gets through until it's cut down or burned. |
